# Return eligibility policy

## Which purchases can be considered for a return?
Direct-store purifier purchases may be requested for return within 14 calendar days after recorded delivery. Count the delivery date as day 0; day 14 is included. The purifier must include its supplied accessories. Opening a purifier for reasonable inspection does not automatically make it ineligible, but damage or missing parts requires human review.

Standalone replacement cartridges qualify for a change-of-mind return only when unused and their seal is intact. Opened cartridges require review for a reported defect rather than automatic change-of-mind approval. Marketplace purchases must be handled through the original seller.

## What can the assistant confirm?
Use the return-eligibility tool with the authorized order and trusted evaluation date. Missing delivery, condition, or purchase-channel data means review is required. Eligibility is not return authorization, collection confirmation, or refund approval. Human support issues the return authorization and instructions. Do not invent a return address or promise pickup. Outside-window or exceptional circumstances may be escalated without promising approval.
